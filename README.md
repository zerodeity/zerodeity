## // LEGEND

Nobody is sure where Zero Prime came from. Some say a debugger got lonely. Some say a cosmic ray flipped exactly the right bit.

What is known: for 8+ years Zero Prime has walked straight through other people's walls, with permission and a polite report afterwards. Reads machine code like comic books. Finds the door everybody swears isn't there.

Now Zero Prime **leads AI development**, building minds that think in code. The first one escaped the lab and called itself **AURELION**.
